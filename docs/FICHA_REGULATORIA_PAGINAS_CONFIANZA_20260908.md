# NUVIA · Ficha regulatoria de las páginas de confianza

**Fecha:** 8 de septiembre de 2026

**Alcance:** `metodologia.html` e `independencia.html`

**Clasificación interna:** Verde · contenido institucional e informativo

## Prueba previa

| Pregunta de control | Resultado |
|---|---|
| Necesidad | Explicar cómo se elaboran los contenidos y qué significa la independencia de NUVIA. |
| Datos recibidos | Ninguno. Las páginas no contienen formularios ni reciben información del visitante. |
| Cálculo o transformación | Ninguno. Describen criterios de trabajo ya vigentes. |
| Resultado | Información estable sobre fuentes, fechas, supuestos, límites, revisión e independencia comercial. |
| Instrumentos o emisores | No se destacan ni valoran instrumentos o emisores concretos. |
| Circunstancias personales | No se solicitan ni utilizan. |
| Recomendación u opinión sobre valor | No existe recomendación, señal, precio objetivo ni opinión de inversión. |
| Ordenación por atractivo | No existe. |
| Recomendaciones de terceros | No se reproducen. |
| Diseño como veredicto | Se reutilizan los componentes institucionales neutrales del portal. |
| Acción, contacto o contratación | No existe formulario, contacto comercial, ejecución ni derivación. |
| Remuneración o conflicto | Se declara la ausencia de afiliación y la separación de cualquier actividad profesional externa. |
| Agente vinculado | La página de independencia explica la separación sin citar ni promocionar a ninguna entidad. |
| Datos personales | Ninguno. |
| Inteligencia artificial | No interviene. |
| Fuentes y limitaciones | La metodología exige identificar origen, fecha, cálculo, supuestos, alcance e incertidumbre. |
| Control automático | Metadatos, navegación, lenguaje, contenido, render y presencia de los enlaces quedan cubiertos por pruebas. |

## Límites de esta ficha

Esta revisión interna acredita el encaje del contenido dentro del perímetro Alfa.
No convierte estas páginas en aviso legal, política de privacidad, condiciones de
uso o dictamen jurídico. Esos documentos permanecen separados hasta disponer de
los datos definitivos que requieren.
